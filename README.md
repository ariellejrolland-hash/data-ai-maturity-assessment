# Data and AI Maturity Assessment

A short, internal self-assessment of where a team stands today, and where it wants to be, across data and AI. Ten themes, each with a main question and a subquestion, answered on a five level maturity scale. The report shows a current versus target radar, a focus list ranked by the gap you choose, and a value equation that names whether the binding constraint is the data, the artificial intelligence, or the human intelligence.

## Use it

Open `index.html` in any browser. It is a single self contained file with no install and no server. Click **View sample report** to see the full output, or enter an organisation, department and role and walk the ten themes.

## What it measures

- Ten themes spanning data foundations (ownership, quality, systems, finding and reusing data, security) and AI readiness (strategy and value, governing AI, AI skills and adoption, process and agents).
- A current and a target level for every question, so low appetite areas drop down the priority list.
- Two headline scores, Data Readiness and AI Readiness, plus a value equation verdict.

## Notes

Intra-organisation tool. Scores reflect the views of the person completing it. Run it across departments and roles to compare perspectives.
