Where to focus, and in what order

Not everything can be a priority at once, so the order matters. The wave shows what should be in place first. Foundations come before AI, because AI only pays off on data people can trust. Within a wave, the gap you chose sets the order, and a weak foundation is flagged to address first even if you set a small target. Wave 1 is foundations (ownership, trustworthy data, reliable systems, security). Wave 2 makes data usable. Wave 3 scales AI.
